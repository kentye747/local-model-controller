# Security reports

Please do not post credentials, raw chat logs, private host information or customer data in a public issue. For a sensitive vulnerability, use GitHub's private vulnerability reporting feature if enabled. Otherwise open an issue stating only that you need a private reporting channel, without exploit details or secrets.

This preview is intended for a trusted local desktop user, not a multi-tenant service. Model endpoints must be loopback HTTP endpoints. SSH monitoring is opt-in and uses the user's existing SSH permissions. This app does not install a remote-access service or broaden system permissions automatically.
